Release map, as a book

Every PR is a story, and you read its draft before it merges. next is the pile of merged stories. A release binds them into a book, with the changelog as its contents page. Shipping publishes the copy that was proofread, and earlier versions stay in the archive. next and main are the default names; .release_flow.yml changes them.
